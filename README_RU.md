# Host Web Launcher

[English version](README.md)

Открывайте веб-интерфейсы хостов — настройки роутера, Proxmox или панели мониторинга — напрямую в новой вкладке браузера, сохраняя Termix открытым.

## Возможности

- Добавление, редактирование и удаление нескольких веб-эндпоинтов для каждого хоста.
- Открытие единственного эндпоинта одним нажатием или выбор сервиса из меню.
- Настройка HTTP/HTTPS, веб-порта, пути, параметров запроса и фрагмента для каждого эндпоинта.
- Использование адреса подключения хоста или отдельного имени, IPv4 либо IPv6 веб-сервиса.
- Стандартный порт протокола, если поле веб-порта оставлено пустым.

Настройте эндпоинты в редакторе хоста в разделе **Host Web Launcher**, затем нажмите **Открыть веб-интерфейс** возле хоста. Каждый сервис должен быть доступен с вашего устройства.

Установка описана в [Installation](docs/INSTALLATION_RU.md), разработка — в [Development](docs/DEVELOPMENT_RU.md).
