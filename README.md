# Host Web Launcher

[Russian version](README_RU.md)

Open your hosts' web interfaces, such as router settings, Proxmox or monitoring dashboards, directly in a new browser tab while keeping Termix open.

## Features

- Add, edit and remove multiple web endpoints for each host.
- Open a single endpoint with one click, or choose a service from a menu.
- Configure HTTP/HTTPS, web port, path, query parameters and fragment for each endpoint.
- Use the host's connection address or a separate web hostname, IPv4 or IPv6 address.
- Leave the web port empty to use the protocol's default.

Configure endpoints in the host editor under **Host Web Launcher**, then use **Open web interface** beside the host. Each service must be reachable from your device.

See [Installation](docs/INSTALLATION.md) for setup and [Development](docs/DEVELOPMENT.md) for contributing.
